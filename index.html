KURAYA 蔵屋

将散落的 JAV 影片，整理成一座带封面与元数据的片库，离线也能从容欣赏。

brew install tenngoxars/tap/kuraya
irm https://kuraya.app/install.ps1 | iex
curl -fsSL https://kuraya.app/install.sh | bash
macOS Windows Linux

装好后运行 Kuraya，按提示选好影片库即可开始。

$

kuraya

完整流程：刮削 → 清理 → 重建页面。

$

kuraya rebuild

只重建片库页面。

$

kuraya --dry-run

预演，不改动任何文件。

$

kuraya --quiet --yes

精简输出，免交互，适合计划任务。
