KURAYA 蔵屋

影片目録

把散乱的影片文件，整理成带封面与元数据的有序收藏， 再生成一册可离线浏览的片库。

安装 Kuraya 查看命令 →

解題

壹

是什么

一部影片，从文件名到一面书架。Kuraya 自动识别番号、取回元数据与封面，按演员与番号归档成册，最后生成一页随时可开的片库。

01

本地优先

元数据、nfo 与海报全部落在本地，与影片文件同存。

02

纯离线片库页

重建出的 index.html 不依赖任何服务，拷走即可浏览。

03

点击即播

点封面即经 kuraya: 协议调起本机播放器，无需中转。

04

无框架测试

自检与测试基于标准库，零第三方框架依赖。

05

三平台二进制

macOS（Apple Silicon）· Windows · Linux 即装即用。

工序

貳

工作流程

三道工序，从散乱到成册。把影片放进「待整理」目录，运行一次即可。

一

识别

从文件名识别番号，联网获取元数据与封面。

二

归档

按 演员名/番号 归档，生成 nfo 与海报。

三

重建

重建片库 index.html，可搜索、筛选、点击封面播放。

片藏

參

片库预览

重建后的片库页面——一页纯离线 HTML，无服务、无追踪，只有你的收藏。

片库 / index.html 搜索番号 · 标题 · 演员…
全部 未观看 按演员 按番号
100 部 · 纯离线 · 可搜索 点击封面即播

点封面即经 kuraya: 协议调起本机播放器 —— 一册离线可读的影片目録。

手引

肆

安装

三平台二进制，一行命令即可。装好后运行 kuraya，按提示选择影片库即可开始。

macOS

仅 Apple Silicon

$ brew install tenngoxars/tap/kuraya

Windows

PowerShell

$ irm https://raw.githubusercontent.com/tenngoxars/Kuraya/main/install.ps1 | iex

Linux

bash

$ curl -fsSL https://raw.githubusercontent.com/tenngoxars/Kuraya/main/install.sh | bash

源码安装

需 Python 3.11 以上

$ git clone git@github.com:tenngoxars/Kuraya.git && cd Kuraya
$ pipx install .

伍

命令行速览

双击运行进入菜单；也可用命令行，便于脚本与计划任务调用。

0 退出

$

kuraya

完整流程：刮削 → 清理 → 重建页面。

$

kuraya scrape --limit 3

只刮削前 3 部，用于试跑。

$

kuraya rebuild

只重建片库页面。

$

kuraya selftest

核对数据源解析规则是否仍有效。

$

kuraya config

查看配置。

$

kuraya --dry-run

只显示将要处理的内容，不改动文件。

$

kuraya --quiet --yes

精简输出、不等待按键，供计划任务使用。
